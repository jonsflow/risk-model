Trading Stage Generator

pipeline/generators/trading_generator.py writes one file per session, data/cache/trading_signals_<date>.json, with one section per stage. Each stage reads only the bars that had ended by its window end, so a run at any time writes the same answer.

Rules

  • A Stage is a model — name, label, window end, timeframes. get_time_series fetches what it describes and nothing else.
  • A stage is available when SPY's data is there through its window end; other symbols without data are left out of the section.
  • Stages never overwrite each other. A later stage reads earlier sections; it never recomputes them.
  • Pages read the sections and show the standard message for a stage that isn't available.
  • tests/test_trading_stages.py replays the latest stored session at 09:00, 09:40, 13:00 and after the close, and checks each stage against the post-close run.
